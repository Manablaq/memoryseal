# Security policy

MemorySeal is deployed on GenLayer Bradbury testnet.

Security boundaries include finalized canonical reads, canonical-address/write-method restrictions, provider-backed wallet writes, no browser private keys, no automatic resubmission after ambiguous submission, context-bound transaction recovery, and immutable finalized contract source evidence.

Candidate/probe contract files are historical and non-canonical. Never include private keys, seed phrases, passwords, or access tokens in reports.
