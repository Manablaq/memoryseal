# MemorySeal contracts

## Canonical deployed Bradbury contracts

Only these files are canonical for the current deployment:

- `memoryseal_claim_consensus.py` — Main
- `memoryseal_registry.py` — Registry

Their finalized addresses, deployment transactions, and exact source SHA-256 values are bound in `../verification/MEMORYSEAL_BRADBURY_FINALIZED_MAIN_V1.json`.

All other candidate, monolithic, and probe Python files in this directory are retained only as historical development artifacts. They are not the deployed canonical contracts.

The canonical Main and Registry source files remain byte-identical to the finalized deployment evidence.
